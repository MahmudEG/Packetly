Infrastructure cheat sheets

Infrastructure references for servers, storage, databases and automation: HPE and Dell health, Linux capacity, Windows DHCP and SMB, Docker, Ansible, Redis, PostgreSQL and MySQL investigations.

17 free references in this topic. Each lists the command, what it inspects and how to read the result.

  • Ansible inventory and playbook preflight — Check configuration, inventory groups, resolved host variables and selected playbook hosts before running automation.
  • Dell Data Domain capacity and health — Inspect filesystem state, capacity and active protection-appliance alerts.
  • Dell Data Domain replication checks — Inspect replication contexts and distinguish idle replication from a stalled copy.
  • Dell PowerEdge hardware inventory — Capture firmware and hardware inventory before planning maintenance.
  • Dell PowerEdge iDRAC health checks — Read PowerEdge identity, power state and hardware event history.
  • Docker container health and restart investigation — Inspect container exit state, health checks, bounded logs, resource usage and published ports during a restart incident.
  • HPE ProLiant iLO health overview — Read ProLiant health and hardware events through iLO.
  • Linux disk space and inode investigation — Distinguish exhausted bytes, exhausted inodes, mount layout and directory growth before deleting any files.
  • MySQL connection and InnoDB lock investigation — Inspect MySQL identity, connection saturation, running sessions, active InnoDB transactions and lock dependencies.
  • PostgreSQL session and blocking investigation — Inspect database identity, connection counts, wait events, blocking relationships and long transactions using bounded SQL queries.
  • Redis memory and latency investigation — Compare Redis identity, memory pressure, eviction counters, client connections and slow-command evidence without scanning the keyspace.
  • VCF 9 ESXi host root password recovery — Recover a managed ESXi host root account through vCenter and PowerCLI, and reconcile VCF credential management.
  • VCF 9 ESXi monitoring and troubleshooting commands — Inspect ESXi 9 identity, resources, networking, storage and time when investigating a VCF workload issue.
  • VCF 9 license server deployment and registration — Plan and verify the dedicated VCF License Server deployment and registration for VCF 9.1.
  • VCF 9 vCenter appliance root password recovery — Reset a forgotten vCenter Server Appliance root password through an authorized SSO administrator and reconcile the VCF credential.
  • Windows DHCP scope and lease investigation — Inspect DHCP scope capacity, leases, reservations, options and failover before changing a production scope.
  • Windows SMB share access investigation — Separate TCP reachability, client SMB connections, share permissions, filesystem ACLs and server-side sessions.
