Dell Data Domain capacity and health

Inspect filesystem state, capacity and active protection-appliance alerts.

Dell Data Domain / PowerProtect DD, DD OS CLI. Verify syntax for your installed DD OS version.

system show versionIdentify DD OS release
filesys statusInspect filesystem availability
filesys show spaceInspect physical and logical space
alerts show currentRead active appliance alerts

Walkthrough

Use an authorized DD management account with read privileges. Preserve alerts and do not run clean, destroy or storage changes from a quick reference.

Identify DD OS release

system show version

Record the system software version and consult the matching command reference. Appliance capabilities and output fields vary between DD OS releases.

Inspect filesystem availability

filesys status

Confirm the filesystem is running before treating a backup error as a client-only problem. A running state does not establish that capacity and integration are healthy.

Inspect physical and logical space

filesys show space

Distinguish pre-compression data from post-compression storage and available physical space. Deduplication ratios alone do not indicate usable headroom.

Read active appliance alerts

alerts show current

Capture alert IDs and severity alongside the time of the backup failure. Investigate capacity, hardware and environmental alerts through the matching vendor runbook.
