Exchange Online mailbox inspection

Connect to Exchange Online and review mailbox identity and quotas.

ExchangeOnlineManagement module; Exchange Online PowerShell.

Connect-ExchangeOnlineOpen an authenticated Exchange session
Get-EXOMailbox -Identity 'user@example.com'Inspect mailbox identity
Get-EXOMailbox -Identity 'user@example.com' -Properties IssueWarningQuota,ProhibitSendQuotaRead mailbox quota settings
Disconnect-ExchangeOnline -Confirm:$falseClose the PowerShell session

Walkthrough

Use an approved Exchange Online account with the required RBAC read permissions. Replace user@example.com with the target mailbox.

Open an authenticated Exchange session

Connect-ExchangeOnline

Complete interactive authentication using your approved admin identity. Verify you are connecting to the intended organization before inspecting recipients.

Inspect mailbox identity

Get-EXOMailbox -Identity 'user@example.com'

Compare primary SMTP address and recipient type with the reported mailbox. A mail-enabled user and an Exchange Online mailbox are different recipient types.

Read mailbox quota settings

Get-EXOMailbox -Identity 'user@example.com' -Properties IssueWarningQuota,ProhibitSendQuota

Request the non-default quota properties explicitly. Compare configured quotas with actual mailbox size before concluding that quota enforcement is causing the issue.

Close the PowerShell session

Disconnect-ExchangeOnline -Confirm:$false

End the session after capturing necessary findings. This disconnects the administrative session; it does not disconnect mailbox users.
