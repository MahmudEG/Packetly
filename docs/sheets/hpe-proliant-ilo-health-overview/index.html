HPE ProLiant iLO health overview

Read ProLiant health and hardware events through iLO.

HPE iLO 6 web interface on supported ProLiant servers; menus differ for iLO 4/5/7.

Information → OverviewConfirm server identity and health
Information → Integrated Management LogInspect hardware events
System Information → Fans / TemperaturesInspect cooling status
System Information → PowerInspect power redundancy

Walkthrough

Use an iLO account with view permissions on the management network. Match the server serial number before investigating.

Confirm server identity and health

Information → Overview

Compare product name, serial number, power state and overall health with the asset record. Information for a powered-off server may reflect its last powered-on state.

Inspect hardware events

Information → Integrated Management Log

Read event severity and timestamps around the incident. Do not clear the IML before preserving the events needed for support.

Inspect cooling status

System Information → Fans / Temperatures

Compare failed sensors and thermal readings with the server-specific limits. Fan speed alone does not identify the failing component.

Inspect power redundancy

System Information → Power

Check power supply presence and status against the intended redundancy configuration. A disconnected redundant feed should be investigated before any physical maintenance.
