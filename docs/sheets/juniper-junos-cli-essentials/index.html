Juniper Junos CLI essentials cheat sheet

Get oriented in Junos operational mode and inspect the chassis.

Junos OS operational mode, prompt ending in >. Output differs by platform.

Updated 2026-11-02 · Juniper · 6 min read

CommandWhat it does
show versionIdentify software and model
show interfaces terseInspect interface summary
show chassis hardwareInspect hardware inventory
show chassis alarmsRead active chassis alarms
show system uptimeInspect boot and system timing

Walkthrough

Use an authorized read-only operational login. These show commands do not require entering configuration mode.

Step 1: Identify software and model

show version

Record the Junos release and hardware model. Consult the command reference for that release before applying examples from another Juniper platform.

Step 2: Inspect interface summary

show interfaces terse

Compare Admin and Link separately, then inspect protocol addresses on logical interfaces. Physical link up does not prove Layer 3 adjacency.

Step 3: Inspect hardware inventory

show chassis hardware

Match installed modules and transceivers with the cabling plan. Empty or absent slots can be intentional; compare against expected inventory.

Step 4: Read active chassis alarms

show chassis alarms

Capture alarm severity, description and timestamp. Use model-specific guidance to distinguish environmental faults from expected conditions.

Step 5: Inspect boot and system timing

show system uptime

Compare boot time and current system time with the incident. On supported Junos platforms this also provides useful timing context for recent configuration activity.

Practical case: A Junos device becomes unreachable after maintenance

Situation

A monitoring system reports that a Juniper device is offline after planned work.

Investigation sequence

1. Identify software and model

show version

Interpret the findings

Compare software and uptime with the maintenance window, interface admin/link state and chassis alarms. A recent boot does not establish why it happened.

Verify the outcome

Verify the management interface and monitoring from the authorized network and retain relevant alarm details.
