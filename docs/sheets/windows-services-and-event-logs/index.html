Windows services and event logs

Build a focused picture of service state and recent system errors.

Windows PowerShell 5.1 or supported PowerShell on Windows.

Get-ServiceList service states
Get-Service -Name SpoolerInspect a specific service
Get-WinEvent -FilterHashtable @{LogName='System'; Level=2; StartTime=(Get-Date).AddHours(-2)} -MaxEvents 30Read recent system errors
Get-Process | Sort-Object CPU -Descending | Select-Object -First 10Inspect cumulative CPU usage

Walkthrough

Use an account permitted to read the selected event log. These commands do not start or stop services.

List service states

Get-Service

Find the affected service and its actual status. A stopped service may be intentional; compare against its startup policy and the application runbook.

Inspect a specific service

Get-Service -Name Spooler

This example checks Print Spooler. Substitute the service name, not its display label. Record status before considering any restart.

Read recent system errors

Get-WinEvent -FilterHashtable @{LogName='System'; Level=2; StartTime=(Get-Date).AddHours(-2)} -MaxEvents 30

Correlate provider, event ID and timestamp with the incident. No matches is different from access denied or a missing log; preserve the distinction.

Inspect cumulative CPU usage

Get-Process | Sort-Object CPU -Descending | Select-Object -First 10

CPU here is accumulated processor time since each process started. It is not a live utilization percentage; confirm a suspected spike with Performance Monitor.
