Sophos Firewall traffic investigation

Walkthrough

Use a read-capable administrator account and a known source, destination and incident time. Availability of traffic records depends on rule logging.

Open firewall traffic logs

Log viewer → Firewall

Set the time window for the reported failure. Confirm that the relevant firewall rule is configured to log traffic before treating an empty log as evidence of no traffic.

Isolate a traffic flow

Filter source IP, destination IP and destination port

Use the translated and original addresses as appropriate to the scenario. Match the exact protocol and port; ping is not a substitute for an application flow.

Read the firewall decision

Inspect action, rule ID and reason

Record the matching rule and drop reason. An allow record shows a policy decision at this device, not successful application authentication or the return route.

Correlate adjacent failures

Compare with VPN and system events

If the destination is across a VPN, compare tunnel events and route state at the same timestamp. Preserve findings before proposing a scoped change.
