Ubiquiti UniFi switch port checks cheat sheet

Inspect switch port state, VLAN assignment and PoE budget.

UniFi Network managed switches; port capabilities vary by model.

Updated 2026-11-02 · Ubiquiti · 7 min read

Walkthrough

Use an authorized UniFi Network administrator with visibility into the correct site. Record the device and port before inspecting settings.

Step 1: Find the physical port

Devices → Switch → Ports → Port Manager

Match the connected endpoint and port number with your cabling map. Do not rely solely on a remembered client name or stale discovery entry.

Step 2: Check the physical link

Inspect link state and negotiated speed

Compare the negotiated rate with both endpoint capabilities. A lower rate can reflect cable faults, negotiation or a legitimate endpoint limitation.

Step 3: Check network assignment

Review native VLAN and tagged VLAN management

Verify the untagged network and allowed tagged networks against the endpoint role. An access device and an AP carrying multiple SSIDs need different VLAN behavior.

Step 4: Check power delivery

Review PoE state and device power budget

For PoE-capable models, compare endpoint demand and remaining switch budget. Do not power-cycle a production endpoint merely to see whether it recovers.
