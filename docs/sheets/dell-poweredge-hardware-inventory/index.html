Dell PowerEdge hardware inventory cheat sheet

Capture firmware and hardware inventory before planning maintenance.

iDRAC9 local RACADM; inventory detail depends on platform and collection state.

Updated 2026-11-02 · Dell · 6 min read

CommandWhat it does
racadm getsysinfoIdentify the system
racadm getversionRead firmware versions
racadm hwinventoryInspect component inventory
racadm jobqueue viewInspect queued management jobs
racadm getselInspect hardware event records

Walkthrough

Use an authorized local RACADM session with inventory read permissions. These commands do not schedule firmware updates.

Step 1: Identify the system

racadm getsysinfo

Record the service tag and model so that any subsequent support lookup uses the correct hardware family.

Step 2: Read firmware versions

racadm getversion

Compare reported firmware versions with your approved baseline. Do not assume that every component shares the same release version.

Step 3: Inspect component inventory

racadm hwinventory

Review NIC, storage controller and other component identifiers. Inventory may reflect the most recent collection; compare with lifecycle events after hardware changes.

Step 4: Inspect queued management jobs

racadm jobqueue view

Check whether existing jobs are pending before proposing maintenance. Viewing the queue does not cancel jobs or restart the host.

Step 5: Inspect hardware event records

racadm getsel

Compare component inventory with recent hardware events and the maintenance timeline. Preserve event records for troubleshooting before clearing logs.

Situation

An administrator must compare firmware and hardware before a scheduled change.

Interpret the findings

Confirm the service tag, versions and inventory, then check hardware events and any queued jobs. An old inventory may not yet reflect a recent component change.

Verify the outcome

Compare the results with the approved baseline and confirm job state before scheduling any update.
