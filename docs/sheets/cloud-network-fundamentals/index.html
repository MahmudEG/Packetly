Cloud network fundamentals cheat sheet

Connect subnets, routes, security rules, and DNS into one model.

Provider-neutral networking concepts. This sheet contains reference concepts rather than executable shell commands.

Walkthrough

Confirm the target device and software release using approved access. Replace angle-bracket placeholders with local values; do not paste placeholders literally. Record the incident time and affected traffic path before collecting output.

Step 1: An address prefix defines a network range

CIDR

Compare source and destination prefixes to establish whether traffic is local or requires a routed path.

Step 2: A segment of a virtual network

Subnet

Identify the source and destination subnets, address ranges and the service endpoint.

Step 3: Maps destination prefixes to next hops

Route table

Trace each applicable route table and next hop, including the return direction.

Step 4: Controls permitted traffic for associated resources

Security group

Compare the relevant stateful security rules with the required source, destination, protocol and port.

Step 5: Resolves internal service names

Private DNS

Resolve the service name from the workload’s environment and compare the result with the intended private address.

Step 6: A subnet-level traffic control in some cloud platforms

Network ACL

Check the platform’s direction, rule ordering and stateful or stateless behavior. Security group and network ACL semantics are provider-specific.

Practical case: A private workload cannot reach an internal service

Fictional teaching scenario; observations are examples, not captured production output.

Situation

Two workloads in different subnets should communicate over a private address.

Interpret the findings

Trace the source subnet, route, network access rules and name resolution in both directions. Provider security controls have different stateful and rule-order semantics.

Verify the outcome

Document the actual path and confirm the service and return traffic after an authorized correction.
