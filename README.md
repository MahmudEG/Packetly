# Packetly

Practical IT, cybersecurity and networking cheat sheets — 57 field guides covering
Windows, Active Directory, Microsoft Graph, Entra ID, Exchange Online, Azure,
FortiGate, Sophos, Cisco, Juniper, Ubiquiti, HPE, Dell, Dell Data Domain, Kali, Linux,
Docker, Kubernetes, curl, AWS, Git, Ansible, Terraform, Redis, PostgreSQL, MySQL and NGINX. Every sheet includes command interpretation,
a step-by-step walkthrough and a fictional practical investigation case.

Live at **https://packetly.ly**

## How it works

A static site generated by Python. No build toolchain, no dependencies.

| Path | Role |
| --- | --- |
| `guides.py` | The 27 long-form field guides. Each row is a triple: *command, purpose, interpretation*. |
| `build.py` | 12 shorter sheets defined inline, plus the generator for every page. |
| `new_guides.py` | 18 extended operations, automation, database, Windows, Linux, container and cloud guides with worked cases. |
| `enrich.py` | Combines existing sheets, command expansions, interpretations and cases. |
| `expansions.py`, `cases.py`, `case_details.py` | Additional commands and platform-specific incident sequences. |
| `docs/` | The published site. GitHub Pages serves this folder. |
| `check_content.py` | Content assertions run before publishing. |

`docs/app.js` and `docs/style.css` are hand-authored and are **not** overwritten by
`build.py`. Everything else in `docs/` is generated.

## Rebuild and publish

```
python build.py
python check_content.py
git add -A && git commit -m "Update sheets" && git push
```

GitHub Pages redeploys automatically on push to `main`.

## Adding a sheet

Append a `guide(...)` call in `new_guides.py` with scope, prerequisites, official
sources, command/purpose/interpretation triples and a complete case. Rebuild and
update the sheet and sitemap counts in `check_content.py` (sheets + homepage +
five information pages + six topic hubs). Example findings must be labeled as
fictional; documented commands are not a claim of lab validation.

## Pages configuration

- Source: branch `main`, folder `/docs`
- Custom domain: `packetly.ly` (`docs/CNAME`)
- `docs/.nojekyll` disables Jekyll processing

## Notes

Issue reports are GitHub issues — the "Report an issue" button on each sheet opens a
pre-filled form. There is no server-side component.
