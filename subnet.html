How to read a /26 subnet

For 192.0.2.70/26, six bits remain for addresses. That gives 64 addresses per block and a mask of 255.255.255.192. The final octet, 70, falls in the block from 64 through 127.

The network address is 192.0.2.64 and the broadcast address is 192.0.2.127. On a conventional LAN, hosts can use 192.0.2.65 through 192.0.2.126.

What changes for /31 and /32?

A /31 on a point-to-point link uses both addresses as endpoints. A /32 identifies one address, commonly used in a host route. The calculator handles these prefixes separately.
