# Packetly search growth — 11 November 2026

## Target and measurement

The target is 5,000 visits per day (about 150,000 per 30 days). This is a target, not a forecast. Current traffic, ranking, search demand and indexing coverage have not been verified. Track GA4 sessions separately from Search Console clicks; they are different metrics.

## Implemented foundation

- All six topic hubs are linked from the sidebar in both original HTML and the interactive page.
- The interactive homepage heading explicitly describes the IT and cybersecurity cheat sheets.
- The 72 guides expose their existing official sources as TechArticle citations.
- Existing canonical URLs, unique titles/descriptions, sitemap, crawler rules, social metadata, and content checks are retained.

## Unlock measurement

1. Verify `https://packetly.ly/` in Google Search Console, if not already verified, and submit `https://packetly.ly/sitemap.xml`. Verification enables reporting; it is not a prerequisite for Google to index a public site.
2. Connect the installed Search Console server using a Google Cloud Desktop OAuth credentials file and sign in. Do not put credentials in this repository.
3. Configure OpenSEO with a DataForSEO account before running paid keyword or competitor queries. No paid research was performed in this pass.
4. Export 28 days of clicks, impressions, CTR and position by page and query; compare with the preceding 28 days. Inspect the homepage, six hubs and representative guides for indexing.

## Prioritized growth work once data is connected

- Improve pages already earning impressions in positions 4–20: match their actual query intent, strengthen the opening answer, and add relevant internal links.
- Validate demand for troubleshooting clusters around FortiGate, Cisco, Windows/AD, Linux and VMware. Treat these as candidates, not proven high-volume keywords.
- Expand only distinct unanswered tasks with official references, version scope, reproducible examples and editorial review. Avoid mass-produced near-duplicate pages.
- Share useful guides in relevant technical communities when allowed, and seek legitimate references from tutorials and documentation collections. No automated promotion has been sent.
- Review weekly: indexed pages, organic sessions, clicks, impressions and top landing pages. Reprioritize monthly based on evidence.

## Sizing the target

A hypothetical 100 pages averaging 50 visits per day would reach 5,000 daily visits. That arithmetic is not evidence of demand or achievable rankings. A defensible forecast requires non-overlapping query demand, present rankings and explicit click-share assumptions from connected data.
